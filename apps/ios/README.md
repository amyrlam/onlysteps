# OnlySteps for iOS

The iPhone app: Sign in with Apple, read steps from Apple Health, upload
daily totals to Supabase, and show weekly group leaderboards.

SwiftUI, iOS 18+, Swift 6. The Xcode project is generated by XcodeGen from
`project.yml`, so it is not committed.

## Folders

| Path | What's in it |
| --- | --- |
| `project.yml` | XcodeGen spec: targets, build settings, the Supabase package. Edit this, not the `.xcodeproj`. |
| `Config/` | `Base.xcconfig` (shared settings: app name, bundle id prefix, URLs) and your own `Secrets.xcconfig` (gitignored). |
| `OnlySteps/App/` | App entry point, `AppConfig` (reads build settings), `AppModel` (sign-in state), root view. |
| `OnlySteps/Core/` | Pure logic with no UI or network: day keys, week ranges, invite links. Unit tested. |
| `OnlySteps/Models/` | Codable types matching the Supabase tables and RPCs. |
| `OnlySteps/Services/` | The Supabase client and `StepSync` (HealthKit reading, background delivery, upload). |
| `OnlySteps/Features/` | Screens: `SignIn`, `Groups` (list, create, join, leaderboard), `You`. |
| `OnlySteps/DesignSystem/` | `Tokens.swift` (generated from `packages/tokens`, don't edit) plus small reusable components with `#Preview`s. |
| `OnlySteps/Support/` | `Info.plist` and the entitlements file. |
| `OnlyStepsTests/` | Unit tests (Swift Testing). |

## Run it

Prerequisites: a Mac with Xcode 16 or newer, and XcodeGen:

```sh
brew install xcodegen
```

1. Copy the secrets file and fill it in:
   ```sh
   cd apps/ios
   cp Config/Secrets.example.xcconfig Config/Secrets.xcconfig
   ```
   - `DEVELOPMENT_TEAM`: your Apple team id (Xcode > Settings > Accounts, or
     developer.apple.com > Membership). Set it here rather than in Xcode's
     Signing tab, because regenerating the project resets that tab.
   - `SUPABASE_URL` and `SUPABASE_ANON_KEY`: from the Supabase dashboard
     (Project Settings > API). Keep the `https:/$()/` spelling; `//` starts a
     comment in xcconfig files.
   - If you fork the app, also change `BUNDLE_ID_PREFIX` (bundle ids are
     globally unique) and `WEB_HOST`.
2. Generate and open the project:
   ```sh
   xcodegen
   open OnlySteps.xcodeproj
   ```
   Run `xcodegen` again whenever you add or remove files or change `project.yml`.
3. Pick the **OnlySteps** scheme and a device, then press Run (Cmd-R). Tests: Cmd-U.

The first build downloads the Supabase Swift package, which takes a minute.

### Things to know

- **Sign in with Apple** needs a paid Apple Developer account, and the Apple
  provider enabled in Supabase (Authentication > Providers > Apple, with the
  app's bundle id as a client id).
- **HealthKit** works in the Simulator, but it has no real steps. Open the
  Health app in the Simulator, choose Browse > Activity > Steps > Add Data to
  add samples. For real data, run on your iPhone.
- **Background sync**: HealthKit wakes the app at most about once an hour when
  new steps are saved. It doesn't run when the app has been force-quit. The app
  also syncs every time it opens and on pull to refresh.
- **Invite links** are `https://<WEB_HOST>/join/<code>`. They open the app only
  once the website serves an `apple-app-site-association` file for the
  associated domain. Until then you can test with the custom scheme, e.g.
  open `onlysteps://join/abc123` in Safari on the device.
- **App name**: change `APP_DISPLAY_NAME` in `Config/Base.xcconfig`. Code reads
  it via `AppConfig.displayName`.

## New to iOS? A short glossary

- **SwiftUI**: Apple's declarative UI framework, a bit like React. Views are
  structs, state lives in `@State` and `@Observable` classes. `#Preview`
  blocks render components live in Xcode's canvas (Editor > Canvas), much like
  Storybook stories.
- **Swift Package Manager (SPM)**: the built-in dependency manager, like npm.
  Packages are declared in `project.yml` under `packages`.
- **XcodeGen**: generates the `.xcodeproj` from a YAML file, which avoids
  merge conflicts in Xcode's project file.
- **xcconfig**: plain-text build settings files, like a `.env` for builds.
- **Entitlements**: capabilities the app asks Apple for (HealthKit, Sign in
  with Apple, associated domains). Xcode's automatic signing registers them.
- **TestFlight**: Apple's beta distribution. Archive in Xcode (Product >
  Archive), upload to App Store Connect, then invite testers.
- **SwiftLint / swift-format**: community linter and Apple's formatter (like
  ESLint and Prettier). Not set up yet; `swift format` ships with Xcode 16.
